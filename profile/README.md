<p>手机用住宅IP这件事，难点不在填参数，而在于系统给不给你填的地方。本文先说清手机走代理的三条路径，再分别讲安卓和苹果的具体菜单位置，然后解释移动数据为什么不行、热点怎么借用，最后给验证方法和几个高频坑。</p>
<h2>一、手机上走代理的三条路径</h2>
<p>第一条是Wi-Fi里的手动代理，安卓和苹果都支持，只对当前Wi-Fi生效。第二条是客户端软件接管流量，灵活但要看权限。第三条是借道，连到已配好的热点或路由器。</p>
<p>三条路径的差别在覆盖范围。手动代理只影响浏览器和遵守系统代理设置的应用，客户端能接管更多流量，借道则是整台设备都走同一条出口，配置最接近电脑。</p>
<h2>二、安卓：Wi-Fi里的手动代理</h2>
<p>路径是设置、网络和互联网、当前Wi-Fi、右上角编辑或长按修改，展开高级选项，把代理改成手动，填主机名和端口，保存后重连一次。填的是IP就写IP，不要写成网址。</p>
<p>保存后打开浏览器访问一个查IP的站点，看到的是美国地址就说明生效。没生效先确认Wi-Fi是否真的重连过，有些机型要断开再连才会应用新的代理参数。</p>
<h3>不同厂商的菜单差异</h3>
<p>原生安卓在"网络和互联网"下，国产系统多放在"WLAN"里，入口位置和叫法都不一样，但关键词都是代理、手动、主机名、端口这四个词，按词找比记路径快。</p>
<h2>三、iOS：手动代理与描述文件</h2>
<p>路径是设置、无线局域网、点当前网络右侧的信息图标，滑到底部配置代理，选手动，填服务器和端口，身份验证按需打开。iOS 的改动同样只对这一个网络有效。</p>
<p>换到别的Wi-Fi或切到蜂窝，代理就自动失效，这是系统设计，不是配置丢了。需要长期生效的场景，得靠客户端软件或者描述文件，后者要信任证书，权限不小。</p>
<h3>描述文件要不要装</h3>
<p>描述文件能一次性改好全局代理，也能被用来收集流量，来源不明的就别装。装之前看清楚签发者、包含哪些配置、能不能随时移除，企业环境里这类管控很常见。</p>
<h2>四、移动数据为什么走不了系统代理</h2>
<p>蜂窝网络没有"代理服务器"这个设置项，系统层面就没给入口。想在4G、5G下走代理，只能靠客户端软件通过本地VPN接口接管，或者干脆用热点借道。</p>
<h3>为什么一出门就失效</h3>
<p>这也解释了一个常见误会：在家Wi-Fi配好能用，出门就"失效"。不是账号出了问题，是网络换了，代理设置没跟过去。</p>
<h2>五、借道：把手机挂到已配好的出口上</h2>
<p>做法有两种。一是手机连一台已经配好代理的路由器发出的Wi-Fi，二是电脑开热点给手机连，电脑上跑代理并允许局域网连接，手机网关指向电脑。</p>
<p>第二种在出差时很实用，一台笔记本带两三个手机，出口统一。缺点是电脑不能休眠，热点一断手机就回到本地网络，业务侧会看到登录地跳变。</p>

<h2>六、验证与几个高频坑</h2>
<p>验证就三步：查IP站点看归属，打开目标应用的登录页看是否正常，再断开重连看设置是否保留，三步都过才算配好。</p>
<p>高频坑有三个：端口填成网页端口、主机名带了http前缀、省电模式掐断后台连接。前两个改参数就好，第三个要在电池设置里放行。</p>

<h2>常见问答</h2>
<h3>安卓手机能同时给两个应用用不同代理吗？</h3>
<p>答：系统自带设置做不到，只提供一条全局代理。要按应用分流，得用支持分应用的客户端，或把不同应用装在不同设备上。</p>
<h3>iPhone 上装了描述文件会影响保修吗？</h3>
<p>答：不影响硬件保修，但会改变网络行为。描述文件可以随时移除，移除后代理立即失效，建议保留原始配置备份。</p>
<h3>手机用住宅IP会不会更耗电？</h3>
<p>答：会有一定增加。代理长连、加密解密要算力，加上客户端常驻后台，耗电比直连高一些，幅度取决于使用时长和机型。</p>
<h3>热点共享给手机，出口地址算谁的？</h3>
<p>答：算电脑那台机器的出口。手机请求经电脑转发，业务侧看到的是电脑所用代理的地址，所以电脑上的配置和在线状态必须稳定。</p>
